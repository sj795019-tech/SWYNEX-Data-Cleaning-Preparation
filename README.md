# SWYNEX - Data Cleaning & Preparation

## Dataset Source
Sales dataset used for the SWYNEX Data Cleaning & Preparation task.

## Dataset Problems Found

The dataset was checked for:
- Missing values
- Duplicate records
- Incorrect data types
- Inconsistent values
- Extra spaces in text fields

## Data Cleaning Performed

### Missing Values
Missing values were identified and handled using appropriate methods.

### Duplicate Records
Duplicate records were identified and removed.

### Data Types
Incorrect data types were identified and corrected.

### Inconsistent Values
Extra spaces and inconsistent capitalization were corrected using TRIM and PROPER.

Excel
